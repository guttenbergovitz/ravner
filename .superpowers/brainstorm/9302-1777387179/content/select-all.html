"Select all" — jak ma działać?

Masz 200 domen, filtrujesz do 12. Zaznaczasz wszystkie — co dostajesz?

A

Select all matching filters (across pages)

Zaznaczenie "Select all" → zaznacza wszystkie domeny pasujące do aktywnych filtrów, nie tylko aktualną stronę. Przy 200 domenach z filtrem "active" możesz zaznaczyć wszystkie 47 aktywnych jednym klikiem — nawet te na stronie 2 i 3.

✕ Cancel ☐ Select all 47 matching — or — ☐ Select 25 on this page
Gdy coś zaznaczone: Scan (47) Delete (47)
B

Select all on current page only

Prostsze — "Select all" zaznacza tylko te domeny które widać na ekranie (max 25). Chcesz więcej? Zmień stronę i zaznacz znowu. Selekcja nie przeżywa nawigacji między stronami.

✕ Cancel ☑ Select all (25) page 1 of 3
Gdy coś zaznaczone: Scan (25) Delete (25)
